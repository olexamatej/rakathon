Pacient Lékař

Lokální demo · bez OCR

Sdílejte seznam léků bezpečně.

Seznam zašifruje tento prohlížeč. Server dostane pouze šifrovaná data a jednorázový PIN.

01

Připravit seznam

Vyberte JSON soubor nebo vložte seznam léků. Soubor zůstává v tomto zařízení.

Očekávaný tvar: objekt s polem medications. Jde o ukázková data; fotografie ani OCR tato verze zatím nezpracovává.

02

Předat přístup lékaři

PIN a dešifrovací klíč předejte odděleně. Klíč se na server neposílá.

Klíč je potřeba předat zvlášť. Lékař otevře web pro lékaře, zadá PIN a vloží tento klíč. PIN samotný seznam nerozšifruje.

Zrušit sdílení

Odkaz lze zrušit před jeho vyzvednutím.

▣

Šifrovací klíč vzniká v prohlížeči. Backend uchovává jen šifrovaný obsah. Používejte pouze syntetická data; tato ukázka není určena pro skutečné zdravotní údaje.
